# Kaustik-Lampe

Interaktive Seite zum Kaustik-Lampen-Projekt: <https://chillchamp1.github.io/kaustik-lampe/>

- **Prototyp:** 3D-Ansicht des Aufbaus mit Tageslichtprojektor, Wasser unter einer Ölmischung fast
  gleicher Dichte und Turbulenz-Antrieb (Magnetrührer unter einem Lochblech). Grenzfläche und
  Deckenmuster stammen aus derselben Simulation.
- **Physik erklärt:** interaktive Vorlesung zu Brechung, reduzierter Schwerkraft, Grenzflächenspannung,
  Dämpfung und Antrieb, mit Live-Simulationen im Browser (direkt: `#physik`).

Die Seite wird aus dem Simulationsprojekt erzeugt (`web/build_combined.py`); dieses Repository enthält
nur das Ergebnis.
